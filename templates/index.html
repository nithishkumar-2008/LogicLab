About LogicLab

What it is

LogicLab is an interactive digital logic simulator. Type a Boolean expression and it builds the truth table and the matching logic-gate circuit.

Purpose

To help students see that Boolean algebra, truth tables and gate circuits are three views of the same logic.

Supported operations

Operators, highest precedence first

Parentheses override the order. Up to 4 variables (A–Z), plus constants 0 and 1.

How to learn with it

  1. Enter an expression or load an example.
  2. Predict each row of the truth table before reading it.
  3. Flip the input switches and watch the highlighted row and the wires.
  4. Read “How it works”, then change one operator and compare.
